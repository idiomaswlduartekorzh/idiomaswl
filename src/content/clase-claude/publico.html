Fundamento 2

Tokens, contexto y uso: tres conceptos, no una sola caja

Tokens

Unidades de procesamiento

El modelo divide el texto en fragmentos. Una palabra puede ocupar uno o varios tokens.

Ventana de contexto

Capacidad del trabajo actual

Incluye instrucciones, historial, archivos recuperados, herramientas y la respuesta en curso.

Límite de uso

Presupuesto del plan

Depende del modelo, esfuerzo, longitud y tipo de tarea. No es idéntico a la capacidad de un chat.

Optimizar no es escribir lo mínimo. Es reducir el trabajo total: menos ruido, menos reintentos y menos correcciones.

Una tarea en Cowork o Claude Code puede consumir más que una consulta simple porque realiza pasos intermedios y usa herramientas.

Ingeniería de instrucciones

Un prompt no es un deseo. Es una especificación de trabajo.

Prompt débil

“Responda la tutela.”

El modelo debe adivinar el rol, la estrategia, el estándar probatorio, las fuentes, el formato y los límites.

Instrucción profesional

Define el trabajo y cómo evaluarlo

Objetivo claro, datos disponibles, procedimiento, entregable, trazabilidad y salvaguardas.

La calidad no depende de una frase mágica. Depende de cuánta ambigüedad operativa eliminamos.

✓Una persona nueva podría ejecutar la tarea sin pedir cinco aclaraciones.
✓La salida se puede revisar con criterios observables.
✓Los vacíos y riesgos quedan explícitos.

Arquitectura del conocimiento

Prompt, Project, Skill y CLAUDE.md no son sinónimos

PromptLo variable de esta ejecución.“Analiza el expediente 2026-017 con estos archivos.”
ProjectContexto compartido para una línea de trabajo.Políticas, plantillas, instrucciones y conocimiento estable.
SkillProcedimiento reusable para una tarea.Pasos, formato, checklist y salvaguardas.
CLAUDE.mdInstrucciones persistentes de directorio en Claude Code.No modificar /originales. Guardar resultados en /outputs.
Regla rápida: variable → prompt · estable de negocio → Project · procedimiento → Skill · convenciones del sistema de archivos → CLAUDE.md.

Actividad 7

Diseñe la automatización antes de activarla

Bonus práctico · Claude Code

Ocho comandos que evitan perder contexto, tiempo y trabajo

Se escriben al comienzo del mensaje. Teclee / para ver los comandos disponibles en su versión y plan.

/context

Muestra qué está ocupando la ventana de contexto.

/compact

Resume la conversación para liberar contexto sin abandonar la tarea.

/clear

Empieza una conversación limpia cuando cambia el objetivo.

/rewind

Vuelve a un punto anterior: conversación, código o ambos.

/resume

Recupera una sesión anterior y continúa donde quedó.

/permissions

Revisa qué herramientas pueden actuar y cuáles deben pedir permiso.

/batch

Divide un cambio grande en unidades independientes y paralelizables.

/help

Abre la referencia de comandos disponible en esa instalación.

Regla de bolsillo: tarea nueva → /clear · contexto valioso pero lleno → /compact · camino equivocado → /rewind · trabajo grande e independiente → /batch.
Resultado de la sesión

La habilidad no es “saber usar Claude”

Es mirar una tarea y separar qué exige criterio, qué puede documentarse y qué puede delegarse con seguridad.

Una vez

Hacer bien la tarea con una instrucción verificable.

Siempre

Convertir el procedimiento estable en Skill.

Después

Delegar o automatizar con permisos y aprobación humana.

Regla final: automatice borradores y tareas reversibles antes de automatizar decisiones o acciones irreversibles.
