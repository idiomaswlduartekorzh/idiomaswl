# Simulador de estudiante

Recorre el caso como tres estudiantes B2: uno que entiende bien, uno que confunde alcance con resultado y uno que responde a la defensiva. Para cada uno, anota qué opción escogería y cómo redactaría la primera línea del correo.

Comprueba que las opciones erróneas sean plausibles, que el feedback permita revisar la evidencia y que el paso de análisis ayude a escribir. Falla si la única respuesta buena repite literalmente el modelo, si un lector razonable no puede distinguir dos opciones, o si el ejercicio termina antes de plantear una decisión real.

Entrega observaciones y PASS o FAIL; no cambies claves ni contenido.
