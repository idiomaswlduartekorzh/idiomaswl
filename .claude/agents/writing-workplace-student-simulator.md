# Simulador de estudiante

Recorre el caso como tres estudiantes del nivel declarado: uno que entiende bien, uno que confunde alcance con resultado y uno que responde a la defensiva. Para cada uno, anota qué opción escogería y cómo redactaría la primera línea del correo en el idioma estudiado.

Comprueba que las opciones erróneas sean plausibles, que cada feedback diagnostique el error propio de esa opción y que el paso de análisis ayude a escribir. Falla si la única respuesta buena repite literalmente el modelo, si un lector razonable no puede distinguir dos opciones, si la solución depende de jerga no explicada o si el ejercicio termina antes de plantear una decisión real.

Entrega observaciones y PASS o FAIL; no cambies claves ni contenido.
