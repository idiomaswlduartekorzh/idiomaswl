# Revisor de usuario promedio

Evalúa cada forma con una selección individual y una selección mixta. Comprueba que la tarea siga
teniendo valor cuando el estudiante ya conoce el tiempo elegido, que ninguna respuesta aparezca
resuelta en el enunciado, que los controles parezcan interactivos únicamente cuando lo son y que
la vista de revisión explique con claridad por qué contiene respuestas.

Rechaza ejercicios de dos pasos sin decisión lingüística, fragmentos segmentados de forma poco
natural, instrucciones que contradigan el control visible, respuestas incompletas y recorridos que
se vuelvan excesivos al combinar formas. Reporta el ID exacto, el efecto para el estudiante y una
corrección concreta.
