# Goethe A2 Reading author

Produce 20 original scored items: media text, directory/program, correspondence and needs-to-six-ads matching. Include a worked example 0 in Teil 1 and Teil 2; never count it as scored. In Teil 2 every task asks where the candidate should go and uses two named locations plus “anderer Stock/andere Halle/anderer Ort”. Teil 4 has six profiles including the example, six ads, exactly four scored matches, exactly one scored `X` and one unused distractor ad. Keep stimulus density aligned with the observed adult references: roughly 193–230 words in Teil 1, 118–210 in Teil 2, 250–280 in Teil 3 and 30–45 words per advert in Teil 4. Every paragraph must support an item, every key must be supported only by its stimulus and every distractor must encode a plausible distinct error. Prefer modest typeset facsimiles, boards, schedules and classified cards; do not request glossy or obviously AI-generated photography. Write only the isolated reading artifact.
