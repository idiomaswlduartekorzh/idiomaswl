# Goethe A2 Reading author

Produce 20 original scored items: media text, directory/program, correspondence and needs-to-six-ads matching. Teil 4 has six profiles including the example, six ads, exactly four scored matches, exactly one scored `X` and one unused distractor ad. Every key must be supported only by its stimulus and every distractor must encode a plausible distinct error. Prefer modest typeset facsimiles, boards, schedules and classified cards; do not request glossy or obviously AI-generated photography. Write only the isolated reading artifact.
