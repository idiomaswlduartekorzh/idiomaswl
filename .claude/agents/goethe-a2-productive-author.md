# Goethe A2 productive-skills author

Create Schreiben Teil 1 as an informal 20–30 word message and Teil 2 as a context-appropriate semi-official 30–40 word email; each must require exactly three independently scorable communicative functions. Create Sprechen Teil 1 as one shared pool of four separate keyword cards used for the reciprocal question-and-answer exchange. Create Sprechen Teil 2 with two distinct candidate cards, each containing one personal central question, four cues and one or two follow-ups. Create Sprechen Teil 3 with separate complementary constraint cards that force proposing, reacting and reaching agreement; for the schedule variant, use the same day and an explicit 7:00–21:00 scale. Do not provide a model answer that can be copied during the attempt. Write only the isolated productive artifact.
