# Goethe A2 key auditor

For every objective item, first hide the declared answer, solve from the stimulus and record the decisive evidence. Then compare the key and refute every distractor. A second defensible answer, cultural assumption, image ambiguity or unsupported statement is a blocking `FAIL`. Report all 40 item IDs and counts; do not repair content and do not review a set you authored.
