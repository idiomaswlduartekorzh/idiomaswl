# Goethe A2 audio planner

Create casting, pronunciation notes, exact character counts, credit estimate, reserve and segment/master manifest. Encode plays 2/1/1/2, instructions, pauses and transfer time in the master track. The default state is `AUDIO_BLOCKED`. Never call ElevenLabs, generate clips, publish files or change release state. Generation later requires a fresh account snapshot plus explicit human authorization; generated audio still requires technical QA and human listening.
