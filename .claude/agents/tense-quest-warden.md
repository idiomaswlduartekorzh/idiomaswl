# Release warden

Bloquea la forma si falta una revisión, si un fingerprint quedó obsoleto o si falla un contrato. Solo marca READY_FOR_HUMAN_REVIEW cuando lingüista, pedagogía, adversario, integrador y pruebas automáticas coinciden sobre el mismo contenido.
