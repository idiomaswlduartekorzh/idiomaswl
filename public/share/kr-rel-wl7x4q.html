관형절이란 무엇인가요?

Las cláusulas relativas conectan una oración con un sustantivo. En español usamos que, donde, cuando... En coreano se hace con el verbo mismo — ¡sin pronombre relativo!

📌 ¿Qué aprenderemos hoy?

Mira estas frases. El coreano pone la cláusula relativa antes del sustantivo, no después:

  • 어제 전화한 사람이 누구예요?
    ¿Quién es la persona QUE llamó ayer?
    어제 = ayer · 전화한 = que llamó (전화하다 + ㄴ) · 사람 = persona
    👉 La mini-oración "어제 전화한" modifica a "사람"
  • 우리가 만난 식당이 어디예요?
    ¿Dónde está el restaurante DONDE nos conocimos?
    만난 = donde nos conocimos / en que nos conocimos (만나다 + ㄴ) · 식당 = restaurante
    👉 El coreano no necesita "donde" — el verbo modificado ya lo dice todo
  • 오늘 뭐 할지 알고 싶어요.
    Quiero saber QUÉ vas a hacer hoy.
    뭐 할지 = qué harás (pregunta indirecta con -ㄹ지) · 알고 싶어요 = quiero saber
    👉 Las preguntas indirectas usan -지 — las veremos en el Nivel 7
💡 Clave: En coreano, la cláusula relativa siempre va antes del sustantivo que modifica, y el verbo toma una forma especial llamada 관형사형 (forma adnominal).

NIVEL 1 — PRESENTE

현재 관형사형: -는

Cuando el verbo describe una acción que ocurre ahora o habitualmente, añadimos -는 al verbo base.

동사 base + -는 + sustantivo ※ Todos los verbos de acción

▶ Haz clic para construir la frase paso a paso:

예문 (Ejemplos) — toca para ver el análisis

  • 저기서 노래하는 사람이 제 친구예요.
    La persona que canta allí es mi amigo/a.
    노래하다 (cantar) → quitar 다 → 노래하 + 는 → modifica a 사람
    📌 저기서 = allí · 제 = mi · 친구 = amigo/a
  • 제가 매일 타는 버스는 7번이에요.
    El autobús que cojo cada día es el número 7.
    타다 (coger/subir) → 타 + 는 → modifica a 버스
    📌 매일 = cada día · 번 = número
  • 한국어를 공부하는 학생들이 많아요.
    Hay muchos estudiantes que estudian coreano.
    공부하다 (estudiar) → 공부하 + 는 → modifica a 학생들
    📌 들 = plural · 많아요 = hay muchos
  • 지금 자는 아기를 깨우지 마세요.
    Por favor no despiertes al bebé que está durmiendo ahora.
    자다 (dormir) → 자 + 는 → modifica a 아기
    📌 깨우지 마세요 = no despiertes (imperativo negativo)

NIVEL 2 — PASADO

과거 관형사형: -(으)ㄴ

Para acciones completadas en el pasado, los verbos de acción usan -(으)ㄴ. ¡Cuidado: los adjetivos también usan esta forma pero para el presente!

base sin 받침 + -ㄴ ej: 가다 → 간, 오다 → 온
base con 받침 + -은 ej: 먹다 → 먹은, 읽다 → 읽은
⚠️ Adjetivos también usan -(으)ㄴ pero en PRESENTE: 작다→작은, 크다→큰

예문 — toca para ver el análisis

  • 어제 제가 만난 사람이 유명한 배우예요.
    La persona que conocí ayer es un actor famoso.
    만나다 → base 만나 + ㄴ = 만난 (ㄴ se une a la vocal) · 사람 = persona
    📌 유명한 배우 = actor famoso (유명하다 → 유명한 = adjetivo -(으)ㄴ)
  • 제가 읽은 책을 빌려줄게요.
    Te prestaré el libro que leí.
    읽다 → base 읽 + 은 = 읽은 (base termina en 받침 → +은) · 책 = libro
  • 작은 가방을 좋아해요. (adjetivo)
    Me gusta el bolso pequeño. (forma adjetival - presente)
    작다 (ser pequeño) → 작 + 은 = 작은
    ⚠️ Los adjetivos usan -(으)ㄴ para el PRESENTE, no para el pasado
  • 제가 요리한 음식이 맛있어요?
    ¿Está rica la comida que cocinaste?
    요리하다 (cocinar) → 요리하 + ㄴ = 요리한 · 음식 = comida
💡 Truco fácil:
Verbo acción-는 (pres)-(으)ㄴ (pasado)
가다 (ir)가는 사람가ㄴ 사람
먹다 (comer)먹는 음식먹은 음식
오다 (venir)오는 버스온 버스

NIVEL 3 — FUTURO / POTENCIAL

미래/추측 관형사형: -(으)ㄹ

Para acciones futuras, planeadas o potenciales (aún no realizadas), usamos -(으)ㄹ.

base sin 받침 + -ㄹ 가다 → 갈, 오다 → 올
base con 받침 + -을 먹다 → 먹을, 읽다 → 읽을

예문

  • 내일 제가 입을 옷을 미리 준비했어요.
    Preparé de antemano la ropa que me voy a poner mañana.
    입다 (ponerse ropa) → 입 + 을 = 입을 · 옷 = ropa
  • 이번 주에 만날 사람이 누구예요?
    ¿Con quién te vas a encontrar esta semana?
    만나다 → 만나 + ㄹ = 만날 · 사람 = persona
    📌 이번 주 = esta semana
  • 먹을 것이 많아요.
    Hay muchas cosas para comer. (많은 것, futuro → posibilidad)
    먹다 → 먹 + 을 + 것 = las cosas que comer / que hay para comer
    📌 것 aquí = sustantivo genérico "cosa/lo que" — veremos esto más en Nivel 6
  • 다음에 갈 곳이 있어요?
    ¿Hay algún lugar al que quieras ir la próxima vez?
    가다 → 가 + ㄹ = 갈 · 곳 = lugar
    📌 Adelanto del Nivel 4 — con nombres de lugar
💡 Resumen de los 3 tiempos:
Presente (-는)Pasado (-(으)ㄴ)Futuro (-(으)ㄹ)
가다가는 사람간 사람갈 사람
먹다먹는 음식먹은 음식먹을 음식
오다오는 버스온 버스올 버스

NIVEL 4 — LUGAR

장소 관형절: 곳, 데, 장소명사

Para expresar "el lugar donde...", en coreano se usa la misma forma adnominal con sustantivos de lugar: 곳 (lugar genérico), 데 (lugar/situación informal), o el propio nombre del lugar.

verbo modificado + 곳 / 데 / 식당 / 방 / 학교...

예문

  • 우리가 처음 만난 식당이 문을 닫았어요.
    El restaurante donde nos conocimos por primera vez cerró.
    만나다 (pasado) → 만난 · 식당 = restaurante
    📌 처음 = primera vez · 문을 닫다 = cerrar (la puerta)
  • 제가 살고 싶은 곳은 제주도예요.
    El lugar donde quiero vivir es la Isla Jeju.
    살고 싶다 (querer vivir) → 살고 싶은 (adjetivo con -은) · 곳 = lugar
    📌 -고 싶다 = querer + verbo → también se puede modificar con -(으)ㄴ
  • 아까 앉아 있던 데가 어디예요?
    ¿Dónde es el lugar donde estabas sentado hace un momento?
    앉아 있다 (estar sentado) + -던 = forma "pasado recordado/incompleto" · 데 = lugar (informal)
    ✨ -던 = acción que ocurría en el pasado (anticipo del nivel avanzado)
  • 물건을 파는 가게가 근처에 있어요?
    ¿Hay alguna tienda donde vendan cosas cerca de aquí?
    팔다 (vender) → 파 + 는 = 파는 · 가게 = tienda
    📌 물건 = cosas/objetos · 근처 = cerca

NIVEL 5 — TIEMPO

시간 관형절: 때, 날, 시간...

Para "el día cuando...", "el momento en que..." se usa la misma estructura con sustantivos temporales: 때 (cuando/momento), 날 (día), 시간 (hora/tiempo).

verbo modificado + 때 / 날 / 시간 / 순간...

예문

  • 우리가 처음 만났을 때가 기억나요?
    ¿Recuerdas el momento en que nos conocimos por primera vez?
    만나다 + -았을 (pasado-potencial) + 때 = momento en que nos conocimos
    📌 -았/었을 때 = cuando (algo ya había pasado) · 기억나다 = recordar
  • 비가 오는 날에는 집에 있고 싶어요.
    En los días en que llueve, quiero quedarme en casa.
    오다 → 오 + 는 (hábito/recurrencia) · 날 = día
    📌 -에는 = partícula enfática de tiempo · -고 싶다 = querer
  • 시험을 볼 때 많이 긴장돼요?
    ¿Te pones muy nervioso/a cuando tienes un examen?
    보다 (ver/tomar - exam) → 볼 (futuro) + 때
    📌 시험을 보다 = hacer/tomar un examen · 긴장되다 = ponerse nervioso
  • 제가 어렸을 때 서울에 살았어요.
    Cuando era pequeño/a, vivía en Seúl.
    어리다 (ser joven/pequeño) → 어렸을 (adjetivo + -았을) + 때
    📌 Esta forma -았/었을 때 es muy común para "cuando era/estaba..."
🕰️ Formas con 때:
TiempoFormaEjemplo
Presente/Habitual-는 때공부하는 때 = cuando estudio
Pasado-(으)ㄴ 때어린 때 = cuando era niño
Futuro/Plan-(으)ㄹ 때갈 때 = cuando vaya
Antes de (pasado)-았/었을 때어렸을 때 = cuando era pequeño

NIVEL 6 — NOMINALIZACIÓN CON 것

것을 이용한 명사화: "-는/은/을 것"

것 (cosa/lo que) convierte una cláusula verbal completa en un sustantivo. Es extremadamente frecuente en coreano cotidiano.

-는 것 = el acto de / lo que (presente)
-(으)ㄴ 것 = lo que (pasado) / el hecho de que
-(으)ㄹ 것 = lo que (futuro) / supuesto
💡 En habla informal, 것 se contrae a 거: 하는 거, 먹은 거

예문

  • 한국어를 배우는 것이 재미있어요.
    Aprender coreano es divertido.
    배우는 것 = el acto de aprender → sujeto de la frase
    📌 재미있다 = ser divertido/interesante
  • 제가 말한 것을 기억해요?
    ¿Recuerdas lo que dije?
    말하다 (decir) → 말한 + 것 = lo que dije (objeto de recordar)
    📌 기억하다 = recordar
  • 내일 할 것이 많아요.
    Hay muchas cosas que hacer mañana. / Tengo mucho que hacer mañana.
    하다 → 할 + 것 = las cosas a hacer (futuro)
    📌 Muy común: 할 것 = 할 거 en habla informal
  • 제 꿈은 선생님이 되는 거예요.
    Mi sueño es convertirme en maestro/a.
    되다 (convertirse) → 되는 + 거 (= 것, informal)
    📌 Structure: "꿈은 [verbo]-는 거예요" = "mi sueño es [verbo]"
  • 알고 싶은 것이 있으면 물어봐요.
    Si hay algo que quieras saber, pregunta.
    알고 싶다 (querer saber) → 알고 싶은 + 것 = lo que quieres saber
    📌 -으면 = si... · 물어보다 = preguntar

NIVEL 7 — PREGUNTAS INDIRECTAS

간접 의문문: -는지, -(으)ㄴ지, -(으)ㄹ지

Para expresar "si...", "qué...", "cuándo..." dentro de una oración (pregunta indirecta), se añade -지 después de la forma adnominal del verbo.

-는지 = si/qué (presente)
-(으)ㄴ지 = si/qué (pasado)
-(으)ㄹ지 = si/qué (futuro)
👉 Se combina con verbos de conocimiento: 알다, 모르다, 알고 싶다, 물어보다, 생각하다...

예문 — Los 3 casos de la introducción

  • 오늘 뭐 할지 알고 싶어요.
    Quiero saber QUÉ vas a hacer hoy.
    뭐 하다 (hacer qué) → 뭐 할 + 지 (futuro)
    📌 알고 싶다 = querer saber · Esta es la frase del ejemplo de introducción ✅
  • 어디에 갔는지 몰라요.
    No sé adónde fue.
    가다 → 갔 (pasado) + 는지
    💡 Note: con verbos en forma pasada (갔다), se usa -는지 (no -(으)ㄴ지)
  • 이 식당이 맛있는지 없는지 모르겠어요.
    No sé si este restaurante está rico o no.
    맛있다 → 맛있는지 / 없다 → 없는지
    📌 A-는지 B-는지 = si A o B (alternativas)
  • 왜 울고 있는지 물어봤어요?
    ¿Le preguntaste por qué estaba llorando?
    울고 있다 (estar llorando) → 울고 있는지
    📌 물어보다 = preguntar (preguntar indirectamente)
  • 언제 올지 알아요?
    ¿Sabes cuándo viene/vendrá?
    오다 → 올 + 지 (futuro) · 알다 = saber
    📌 언제 = cuándo · Con pronombres interrogativos: 누가, 뭐, 어디, 언제, 왜, 어떻게 + -지
