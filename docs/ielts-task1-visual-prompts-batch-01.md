# IELTS Task 1 Visual Prompts - Batch 01

These prompts are for original WeLearn practice visuals. They are IELTS-style, not official IELTS material.

## Shared instruction

Append this block to every prompt:

```text
Generate the visual now. Do not ask for missing information: the visual type, title, labels, categories, values and units are all specified below and are final. Do not invent, round, reorder, duplicate or omit any value. All visible text must be accurate English. If exact labels or numbers cannot be rendered reliably, return DATA_RENDERING_ERROR instead of generating a defective image. Use a clean 1600x1000 horizontal WeLearn Original Practice layout with a white/pale-lavender background, navy #173B8F, red #D51F3D, a thin navy frame, small red and navy corner capsules, and the label “WeLearn Original Practice”. Do not use IELTS, Cambridge, British Council or official examination logos.
```

## Corrected prompts

### 01. Line graph - Internet access

```text
Visual type: line graph.
Title: “Internet access in three regions, 2000–2020”.
X-axis: 2000, 2005, 2010, 2015, 2020.
Y-axis label: “Percentage of population”; scale 0%, 20%, 40%, 60%, 80%, 100%.
Series and exact values:
- Region North: 30%, 48%, 62%, 77%, 89%.
- Region Central: 14%, 27%, 45%, 64%, 79%.
- Region South: 7%, 10%, 22%, 39%, 57%.
Use three distinct lines, a legend and data labels. All three series rise; no lines cross.
```

### 02. Line graph - Public transport

```text
Visual type: line graph.
Title: “Public transport trips by mode, 2010–2025”.
X-axis: 2010, 2015, 2020, 2025.
Y-axis label: “Million trips”; scale 0, 20, 40, 60, 80, 100.
Series and exact values:
- Bus: 82, 78, 69, 73.
- Rail: 41, 49, 64, 81.
- Tram: 18, 25, 31, 39.
Use a legend and data labels. Bus declines then recovers; rail rises and overtakes bus between 2020 and 2025; tram rises steadily.
```

### 06. Bar chart - Education spending

```text
Visual type: grouped vertical bar chart.
Title: “Government spending on education in five countries, 2010 and 2020”.

Y-axis label: “Percentage of national budget”; scale 0 to 10.

- 2010: Canada 5.2, Finland 6.4, Japan 4.1, Mexico 4.8, Spain 4.5.
- 2020: Canada 6.1, Finland 7.3, Japan 5.0, Mexico 5.6, Spain 5.2.
Use two legend colours, one pair per country, with values printed above every bar.
```
