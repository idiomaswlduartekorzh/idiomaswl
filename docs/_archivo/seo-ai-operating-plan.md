# Instrucción Maestra SEO + AI SEO - Idiomas WeLearn

Fecha: 2026-07-09
Estado: borrador operativo para ejecutar por fases

## 1. Propósito

Este plan define cómo convertir idiomaswl.com en una referencia de calidad, claridad y utilidad para:

- SEO tradicional en Google.
- SEO para respuestas de IA y buscadores asistidos por IA.
- Conversión real a leads, no solo tráfico.

La regla central es simple:

1. Lo que ya funciona, se fortalece.
2. Lo que funciona a medias, se optimiza.
3. Lo que confunde a Google o al usuario, se corrige.
4. Lo que el usuario busca y no existe, se crea.

## 2. Principios de trabajo

### 2.1 Prioridad del usuario

Cada página debe responder primero una intención real de búsqueda y después una necesidad de negocio.

### 2.2 Prioridad de claridad

Cada URL importante debe dejar claro, en este orden:

- Qué es.
- Para quién sirve.
- Qué resuelve.
- Qué acción debe tomar el usuario.

### 2.3 Prioridad de indexabilidad

Toda página que queramos posicionar debe tener:

- Canonical correcto.
- Título único.
- Meta description útil.
- H1 único.
- H2 y H3 con estructura lógica.
- Texto visible suficiente.
- Enlazado interno.
- Schema coherente con lo visible.

### 2.4 Prioridad de conversión

No basta con aparecer. Cada página debe empujar una acción:

- WhatsApp.
- Formulario.
- Diagnóstico.
- Clase.
- Registro.
- Simulacro.

### 2.5 Prioridad de IA friendly

La información debe estar escrita para que una IA la pueda entender, resumir y citar con facilidad:

- Respuesta directa al inicio.
- Definiciones claras.
- Tablas comparativas.
- Listas concretas.
- Fechas y datos visibles cuando aplique.
- Entidades consistentes: marca, cursos, exámenes, niveles, ciudades, certificaciones.

## 3. Regla de decisión por página

Cada URL se clasifica en una de estas cuatro categorías:

### A. Motor

Páginas que deben traer tráfico y leads.

Ejemplos:

- Clases de inglés.
- ICFES.
- IELTS.
- TOEFL.
- TOPIK.
- Goethe.
- DELF/DALF.
- CELI/CILS.
- Celpe-Bras.

### B. Soporte

Páginas que ayudan a que los motores ganen autoridad.

Ejemplos:

- Artículos explicativos.
- Guías comparativas.
- FAQs.
- Glosarios.
- Contenidos de método.

### C. Conversión

Páginas creadas para capturar lead o acelerar decisión.

Ejemplos:

- Precios.
- Diagnóstico.
- Simulacros.
- Tests.
- Landings locales.

### D. Técnico / control

Páginas que existen para operar el sitio pero no deben competir por tráfico.

Ejemplos:

- Legal.
- Auth.
- Dashboard.
- APIs.
- Preview.
- Flujos internos.

## 4. Instrucción por página

Toda página pública importante debe pasar por esta lista:

1. ¿Qué query quiere capturar?
2. ¿Qué intención resuelve?
3. ¿Qué aparece en el link azul?
4. ¿Qué aparece debajo del link azul?
5. ¿Qué ve el usuario al entrar?
6. ¿El H1 confirma la promesa?
7. ¿Los H2 ordenan la idea?
8. ¿Los H3 desarrollan sin ruido?
9. ¿Hay una respuesta útil antes de obligar a scrollear mucho?
10. ¿Hay CTA claro?
11. ¿La página tiene enlace interno desde y hacia otros hubs?
12. ¿Está indexable y con canonical correcto?
13. ¿Puede ser entendida por IA sin contexto adicional?

## 5. Estándar SEO de contenido

Cada pieza pública debe seguir esta estructura mínima:

- Título orientado a intención.
- Meta description que venda el valor real.
- H1 que coincida con la promesa principal.
- Introducción con respuesta directa.
- Sección de contexto.
- Sección práctica.
- Sección comparativa o de pasos, si aplica.
- FAQ final.
- CTA final.

### 5.1 Qué debe salir en Google

El objetivo del snippet es que el usuario sienta:

- "Esto responde exactamente lo que busco."
- "Esto es actual."
- "Esto es útil."
- "Esto parece confiable."

Para lograrlo:

- El title debe ser específico, no genérico.
- La description debe resumir beneficio, prueba y acción.
- El H1 debe ser claro y humano.
- Los primeros 100-150 palabras deben resolver la intención.

### 5.2 Qué debe salir al entrar

La primera pantalla de cada página debe contener:

- Promesa clara.
- Respuesta inicial.
- Una prueba o dato útil.
- Una ruta de siguiente paso.

## 6. Plan de ataque general

### Fase 1. Limpieza de base

Objetivo: que el sitio esté técnicamente sano y entendible.

Acciones:

- Unificar `www` como forma canónica.
- Resolver 404.
- Revisar `noindex`.
- Definir si la home canónica será `/` o `/home`.
- Limpiar canonicals inconsistentes.
- Revisar sitemap para que solo incluya lo que realmente debe competir.

Resultado esperado:

- Google entiende qué páginas importan.
- No hay señales contradictorias.
- La autoridad se concentra.

### Fase 2. Mapa de negocio

Objetivo: decidir qué grupos de páginas son estratégicos.

Bloques principales:

- Inglés general y comercial.
- ICFES.
- IELTS.
- TOEFL.
- Cambridge.
- Coreano / TOPIK.
- Francés / DELF / DALF / CELI / CILS.
- Alemán / Goethe.
- Portugués / Celpe-Bras.
- Páginas locales por ciudad.

Resultado esperado:

- Cada familia de búsquedas tiene su hub.
- Cada hub tiene subpáginas útiles.
- No se compite con páginas gemelas o repetidas.

### Fase 3. Reescritura de motores

Objetivo: convertir las páginas clave en páginas insignia.

Para cada motor:

- Reescribir title, meta y H1.
- Reorganizar H2 y H3.
- Agregar introducción clara.
- Incluir tabla o comparativa si ayuda.
- Añadir FAQ.
- Añadir CTA específico.
- Conectar con otras páginas del cluster.

Resultado esperado:

- El usuario entiende la página de inmediato.
- Google entiende la relevancia temática.
- La IA puede resumirla con facilidad.

### Fase 4. Creación de páginas faltantes

Objetivo: cubrir búsquedas que hoy existen pero no están atendidas.

Regla:

No crear contenido por volumen.
Crear solo cuando exista una intención clara, una oportunidad comercial o una brecha temática real.

Ejemplos de páginas a crear o consolidar:

- Cómo preparar el ICFES de inglés.
- Simulacros ICFES de inglés.
- IELTS vs TOEFL en Colombia.
- Qué certificación de inglés conviene según objetivo.
- Curso de coreano online en Colombia.
- TOPIK desde cero.
- Goethe en Colombia.
- DELF B2 en Colombia.
- CELI / CILS en Colombia.
- Celpe-Bras en Colombia.
- Inglés para trabajo en Estados Unidos.
- Inglés para negociaciones internacionales.
- Nivel de inglés para grado universitario.
- Cuánto tarda llegar a B2.

Resultado esperado:

- El sitio cubre búsquedas reales.
- Se amplía la huella temática sin perder calidad.

### Fase 5. Conversión y autoridad

Objetivo: que el tráfico tenga un camino claro hacia lead.

Acciones:

- CTA por intención.
- Formularios medidos.
- WhatsApp medible.
- Landing local.
- Prueba social.
- Testimonios.
- Autoría visible.
- Página "Sobre WeLearn" sólida.

Resultado esperado:

- Más clics se convierten en contacto.
- Más confianza reduce rebote.
- La marca gana credibilidad.

### Fase 6. AI SEO

Objetivo: que la web sea fácil de comprender y citar por sistemas de IA.

Acciones:

- Textos claros y directos.
- Definiciones explícitas.
- Tablas comparativas.
- FAQ coherentes.
- Entidad de marca sólida.
- Estructura consistente en todos los cursos y exámenes.

Resultado esperado:

- Más probabilidad de aparecer en resúmenes de IA.
- Mayor claridad semántica en todo el sitio.

## 7. Orden de ejecución recomendado

### Onda 1: urgente

1. Canonical y dominio.
2. 404.
3. `noindex`.
4. Home canónica.
5. Sitemap limpio.
6. Medición de leads.

### Onda 2: impacto rápido

1. Páginas con más impresiones y bajo CTR.
2. Titles y descriptions.
3. H1/H2/H3.
4. FAQs.
5. Enlazado interno.

### Onda 3: crecimiento

1. ICFES.
2. Inglés comercial y local.
3. IELTS / TOEFL / Cambridge.
4. Coreano / TOPIK.
5. Francés, alemán y portugués.

### Onda 4: consolidación

1. Autoridad externa.
2. Reviews.
3. Google Business Profile.
4. Contenido de marca.
5. Benchmarks en buscadores de IA.

## 8. Criterio para no dañar calidad educativa

La calidad educativa no se negocia. Antes de publicar o modificar una página, debe responder:

- ¿Ayuda de verdad?
- ¿Explica mejor que la competencia?
- ¿Evita relleno?
- ¿Está al nivel de la intención?
- ¿Tiene una siguiente acción clara?

Si la respuesta es no, se reescribe o no se publica.
