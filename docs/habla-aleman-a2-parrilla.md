# Habla acompañada · Alemán A2 · parrilla editorial 1–20

Estado: **matriz 20/20 preparada para autoría; todavía no publicada.** Es el siguiente conjunto
de la fase A2 de [`habla-acompanado-blueprint.md`](habla-acompanado-blueprint.md). Las situaciones
se escriben directamente en alemán y no traducen las colecciones existentes.

## Decisiones lingüísticas

- **Variante:** alemán estándar contemporáneo. Se mantiene **Sie** en servicios y con personas
  desconocidas; **du/ihr** queda para colegas, amistades y vecinos conocidos. Cada ficha declara
  el tratamiento y lo conserva durante toda la interacción.
- **Alcance A2:** resolver un problema cotidiano con datos concretos, una petición, un límite,
  una alternativa y una confirmación. No se exige debatir normas ni justificar opiniones abstractas.
- **Interacción real:** ambos roles guardan información necesaria. Ni una ficha ni la caja común,
  leídas en orden, contienen la conversación completa.
- **Contexto explicado:** Pfandbon, Bürgerbüro, Hausordnung, Volkshochschule, Packstation,
  Ersatzbus y Weihnachtsmarkt se definen operativamente cuando aparecen.
- **Carga alemana:** las fichas favorecen oraciones principales claras y subordinadas breves con
  *weil*, *wenn* y *dass*. Los compuestos largos se explican; no se convierten en una prueba B1.
