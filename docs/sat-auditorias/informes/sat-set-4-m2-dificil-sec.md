## Regla única y montaje

| ID | Clave | Regla aislada |

| q16 | D | coma después de subordinada concesiva inicial |
| q17 | B | punto y coma entre independientes y coma después de *however* |
| q18 | A | guiones largos emparejados alrededor de aposición no esencial |
| q19 | C | dos puntos para introducir dos categorías después de oración completa |

Se montaron las cuatro opciones de cada hueco. q17 conserva una sola solución: la opción
con punto no lleva la coma necesaria después de *However*. q18 tiene un guion de cierre
impreso, por lo que solo el guion inicial empareja el inciso. q22 no ofrece pasado simple,
que podría ser defendible en una lectura narrativa menos estricta.
